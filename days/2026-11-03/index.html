阿里 · 2026-11-02
CaPtain：把「SFT + 多轮 RL」配方搬到机器人代码策略，4B 开源小模型反超前沿闭源 Agent

一句话：开源后训练流水线：让策略对着机器人 API 写代码（Code-as-Policy），先用合成轨迹 SFT 对齐接口，再用带「物理 critic」的多轮 RL 精调；从 Qwen3.5-4B（零样本 0%）出发，LIBERO 上 SFT 后 55.4%、RL 后 73.8%，LIBERO-PRO 78.5% 超过多个前沿模型 Agent，并可迁移到真机。

为什么值得看：「先学接口、再靠 RL 精通」这条在编程 Agent 上验证过的配方第一次系统搬进机器人操作，且代码、数据、权重全开源；物理 critic 利用仿真特权信息给每步请求记信用，是长链路奖励归因的漂亮设计。

学术界 · 2026-11-02
LLM 强化学习的训练-推理错位从哪来？拆解「数值偏差」与「策略滞后」并给出 DLC 校正

一句话：把 RL 训练中采样器与训练器之间的错位拆成两部分：近乎恒定的数值偏差，以及会随训练步累积的策略滞后；据此推出 discrepancy-lag correction（DLC），让使用过期采样的 stale-sampler 训练保持在 on-policy 运行的噪声范围内。

为什么值得看：异步 RL 管线里「采样器用的是旧策略」是吞吐与稳定性的核心矛盾，这篇给出了可量化的拆分和可直接落地的校正项——做 RL Infra / 后训练工程的人值得精读的机制型论文。
