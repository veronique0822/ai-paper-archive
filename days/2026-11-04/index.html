OpenAI · 2026-11-03
奥特曼 ADIPEC 演讲预告「下一代 GPT」：1 万个无层级 Agent 协作 88 小时攻克纳维-斯托克斯难题

一句话：奥特曼在阿布扎比 ADIPEC 2026 开幕式上确认：9 月证明千禧年难题 NS 方程（有限时间奇点情形）的内部模型就是即将发布的下一代 GPT——1 万个 Agent 在无总控、无层级的情况下协作约 88 小时完成核心探索，交换 270 万条消息、生成约 1300 亿 Token，随后 GPT-6 Astra 用 17 小时完成 Lean 形式化验证。

为什么值得看：这是「万级 Agent 自主协同科研」第一次与下一代旗舰模型官方挂钩：Agent 自选方向、实时共享进展、第 50 小时一支小分队打开缺口后数千 Agent 自发转向——多智能体编排的候选人聊这个话题，立刻能分出「看过新闻」和「想过架构」两档。

Moonshot · 2026-11-04
Kimi K3.1 Pro 完整权重今日按计划开放：开源权重模型首次跻身全球智能榜前四

一句话：月之暗面按计划于 11 月 4 日前开放 K3.1 Pro 完整权重：2.8 万亿总参数（激活 1040 亿）、100 万上下文，Artificial Analysis 智能指数 55 分位列全球第四；Terminal-Bench 4.0 得 65.7% 超过 GPT-6 Astra（58.2%）、距 Claude Opus 5.5（66.4%）仅 0.7 分，API 价格较 K3 下调三分之一。

为什么值得看：「可自部署的最强开源模型」正式换人，开源与闭源的差距从 12 分缩到 3 分——有本地部署/微调需求的团队选型清单要重排；Moonshot 主动剔除网络安全训练数据并公开削减幅度（xdev-bench-hard 90.5%→81.0%），这种透明在开源发布中几乎没有先例，安全治理话题的好素材。

上海AI Lab、南洋理工大学 · 2026-11-03
PhysLDM：物理仿真的 Latent Diffusion 范式，一次性生成整段高保真形变轨迹

一句话：首个面向体网格可变形动力学的高保真时空自编码器+隐空间扩散范式：把每帧拆成「刚体运动+局部形变」，用一组可学习时间 query 把整段轨迹压缩至 78 倍，再用扩散模型一次生成；毫米级重建精度、零样本泛化到未见物体，端到端可微。

为什么值得看：一个反直觉发现是全文灵魂：同一输入在 GPU 求解器上跑五次，终点能差 442 毫米——物理仿真本质是「多解」的，扩散模型天然比回归更懂这种混沌；可微特性还能 40 秒反推材料刚度（传统可微仿真要 20 多分钟甚至失败），世界模型与机器人仿真方向都值得跟进。

Taiming Lu、Qi Xu、Zhigang Hua、Zhuang Liu 等 · 2026-11-02
Strategist：让「推理策略」自我进化的元 Agent——30 个基准上 24 个反超最强基线，推理成本反降 39%

一句话：把 Agent 系统中「怎么调用模型」的推理策略写成可复用的代码蓝图（blueprint）：元 Agent 检索相关蓝图、生成候选策略、在真实样本上测试并修订，全部入库供后续任务复用；30 个基准上 24 个胜过最强基线（74.7% vs 74.0%）且推理成本降低 39%，策略无需再次搜索即可迁移到新任务与其他模型。

为什么值得看：它指出一个常被忽视的事实：模型只是 Agent 系统的一半，另一半「推理策略」长期靠手写、经验无法沉淀；把策略库做成可积累资产，等于给 Agent 工程补上了「自我改进」的拼图——做 Agent 编排与推理优化的团队可直接借鉴。
