NSA 被曝每年支付数十亿美元测试 AI 模型（华盛顿太阳报援引机密评估）

一句话：机密评估显示：NSA 每年投入数十亿美元用于测试（并尝试红队攻破）前沿 AI 模型，预算规模与增长曲线首次被媒体拼出全貌。

2 ｜ 论文 ｜ IBM ｜ 2026-09-25
Memory as Middleware：把记忆做成 Agent 的可插拔中间件（IBM Research）

一句话：IBM 提出把「记忆读写」从 Agent 应用代码里抽出来变成独立中间件层：统一接口、按用途分库、支持跨应用共享记忆，并给出自改进 Agent 的参考实现。

为什么值得看：Agent 记忆正在从「每个应用自己造轮子」走向「平台层标准件」——和数据库当年从应用代码中独立出来的路径几乎一样，做 Agent 平台/Infra 方向的人选一定会被问到这一层怎么设计。

3 ｜ 论文 ｜ 2026-09-25
Before the Rollout Ends：长程 Coding Agent 的「提前结算」奖励预测

一句话：在 rollout 还没跑完时就用部分轨迹预测最终奖励，让长程编程 Agent 的 RL 训练不必等整条任务结束才回传信号，样本效率与收敛速度同步提升。

为什么值得看：长程 Agent 训练的卡点之一是「奖励太稀疏、反馈太滞后」：提前结算相当于给训练装上仪表盘，是聊 Agentic RL 工程细节（credit assignment、样本效率）时的具体抓手。

4 ｜ 论文 ｜ 2026-09-25
GT-VLA：给机器人操作加上「目标轨迹引导」的泛化 VLA 模型

一句话：在视觉-语言-动作模型中引入以目标物体为条件的轨迹引导信号，让机器人在新物体、新位姿下依然能规划出可执行动作，泛化能力显著优于基线 VLA。

为什么值得看：VLA 路线的核心难题是「训练分布之外的物体怎么办」：把「要去哪」显式编码进条件，是绕开海量数据覆盖问题的一条巧路，聊具身岗位时可用来探候选人对 condition 设计的理解。
