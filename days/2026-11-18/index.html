学术研究 · 2026-11-16
VoxMel TTS 技术报告：抛弃声学 tokenizer，直接在连续 Mel 频谱空间做自回归语音合成（arXiv:2611.20254）

一句话：当日 Hugging Face 日榜热度最高的论文（75 票）：自回归 TTS 的主流路线是先把声音压成离散 token 再让语言模型生成，VoxMel 反其道而行——不训练声学 tokenizer，直接在连续 Mel 频谱空间做自回归生成，用小波分解把不同频段的声学信息分层建模，绕开「tokenizer 损失上限」这个老问题。

为什么值得看：语音赛道正在复刻图像生成从「离散 token」回归「连续表示」的历史——如果连续空间路线成立，语音模型的音质上限和数据效率都会被重写；做语音/多模态方向的人，「去 tokenizer 化」是今年值得跟踪的技术暗线。

学术研究 · 2026-11-16
SPILLWAY：把「目标准入」与「内容消毒」拆开，AgentDojo 上唯一全格零攻破的提示注入防线（arXiv:2611.07222）

一句话：针对工具调用 Agent 的提示注入攻击，SPILLWAY 提出确定性防线：只有来自「用户明确输入的工具参数或任务本身」的目标才被准入执行，自由文本里的注入指令在准入层就被拦下，而不是事后靠模型「消毒」；在 AgentDojo 基准七种防御方案中，它是唯一在全部 12 个「骨干模型×攻击套件」格子里实现零在册攻击成功的方案，且即插即用（SPILLWAY 1.0.0 已开源）。

为什么值得看：和本周 GTIG 报告的 settings.json 后门是同一枚硬币的两面：Agent 安全的实战重心正从「模型会不会被骗」转向「外围系统的确定性约束」——不靠模型自觉、靠架构保证；做 Agent 安全工程的人，deterministic guardrail 这个词可以进 JD 了。

Anthropic · 2026-11-17
Anthropic 的 Agent 记忆实验：关键不是「存多少」，而是「忘掉什么」——Pokémon 实测 413 份笔记拖垮老模型

一句话：Anthropic 用 Pokémon Red 实测 Agent 记忆策略：老模型 Claude Sonnet 3.7「什么都记」，1 万步游戏写了 413 个文件、225 个文件夹，后期光整理笔记不玩游戏，只拿到 1 枚徽章；新模型 Claude Fable 5 只记策略和验证过的规则，拿到 4 枚。结论：给强模型讲清记忆的「目的」、让它自己决定记什么，比硬性规则（如「只记错误」）更有效；其 Dreaming 记忆整理服务（读最多 100 个历史会话、去重去旧）仍在研究预览阶段。

为什么值得看：Agent 记忆是明年产品差异化最确定的战场之一，Anthropic 这篇把「记忆工程」从玄学变成了可讨论的设计原则（少即是多、定期整理、防止错误笔记污染未来会话）；和候选人聊 Agent 产品设计时，这是一个现成的、有画面感的追问素材。
