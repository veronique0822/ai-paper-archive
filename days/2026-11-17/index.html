Anthropic IPO 进入读秒：11 月 19 日挂牌纳斯达克，科技七巨头 260 亿美元私募配售护航

一句话：发行价区间 70-78 美元，发行 8.25 亿股，基础发行最高募资约 644 亿美元；叠加谷歌、微软、英伟达、AMD、博通、美光、台积电按发行价认购的 260 亿美元 N 类股私募配售，合计最高 904 亿美元；按上限定价市值约 1 万亿美元、完全摊薄约 1.4 万亿美元；预计 11 月 18 日定价、次日开始交易，股票代码 ANT。

英伟达 CEO 真空搅动「AI 一哥」之争：SemiAnalysis 称 Anthropic 受冲击远小于 OpenAI

arXiv · 2026-11-13
ModHarness-RL：把 Agent 的「脚手架」也变成可学习、可进化的程序（arXiv:2611.18533）

一句话：Agentic RL 普遍在固定的人工脚手架（harness——决定模型看到哪些交互信息、收到什么引导的外围程序）下训练，但好脚手架随领域、数据与模型状态不断变化；ModHarness-RL 把交互记录为结构化 State 类型块，将脚手架的压缩与引导两个核心组件改写成可学习程序，随 RL 训练一起进化。

为什么值得看：Agent 赛道正在从「调模型」转向「调模型周围的系统」——脚手架可学习意味着上下文/编排工程从手艺变成可优化对象；招 Agent 工程方向的人，「harness engineering」这个词可以开始写进 JD 和面试题了。

arXiv · 2026-11-13
Gamer：面向长程实时任务的通用游戏智能体，键鼠级操作打通 2D 界面与 3D 世界（arXiv:2611.18397）

一句话：通用 VLA（视觉-语言-动作）智能体框架：在数万小时设备级键盘鼠标交互轨迹上继续预训练，轨迹横跨模拟游戏与具身环境，让模型同时学习物理与虚拟世界的动态规律；配合稀疏思考指令微调，端到端整合感知、记忆管理与多步推理，同一套训练与部署管线同时支持传统 2D 图形界面和复杂 3D 模拟世界。

为什么值得看：「用游戏练出来的操作能力迁移到电脑操作」是 Computer Use 赛道的平价数据路线——数万小时键鼠轨迹比真实办公软件数据好拿得多；做 GUI Agent、具身智能方向的团队会关心它的数据配方。

Google DeepMind 等 · 2026-11-13
可解释性实战：线性探针能在网页 Agent「幻觉操作」发生前预警，AUC 达 0.80（arXiv:2611.18514）

一句话：机制可解释性（MI，即打开模型「黑箱」观察内部神经活动）一直被质疑只能解释玩具任务；本文以真实网页 Agent 的经典翻车场景——幻觉出页面上不存在的可点元素——做案例：对 Qwen2.5-7B 最后一个提示 token 训练线性探针，可在生成开始前以 0.80 AUC 预测幻觉，且引导向量干预可降低幻觉；资深作者 Mor Geva 来自 Google DeepMind。

为什么值得看：「在 Agent 动手前就知道它要犯错」正是 Agent 安全监控最想要的能力——这篇把 MI 从论文秀场拉进 Agent 可靠性工程；做 Agent 评测与安全监控方向的岗位，「探针预警」很快会变成面试常考题。

arXiv · 2026-11-13
WeightBench：让大模型直接「读写」别的神经网络的权重，42 项任务开出第一套考卷（arXiv:2611.18553）

一句话：权重空间编程（WSP）：大模型不经梯度下降，直接读懂一个网络的训练目标、修好坏网络、甚至从零写出可用网络；WeightBench 用 42 项任务、五条赛道（读权重、修权重、写权重、识别不可能编辑、无数据压缩）系统评测不同能力档的 LLM，被操作的网络从 2K 参数的控制器起步。

为什么值得看：上周无涯智远的对照实验刚给这条路线泼过冷水，这周考卷就来了——如果模型真能直接操作权重，「训练」可能被「生成」部分替代，这是比 RSI 更激进的自我改进路径；目前还在玩具规模，但范式信号值得招聘经理放进观察清单。

MIT · 2026-11-13
MIT「Alignment by Socialization」：用演化选择让 Agent 学会在规则与任务之间做权衡（arXiv:2611.18531）

一句话：MIT 学者（含金融工程名家 Andrew W. Lo）研究选择压力如何塑造 Agent 在「完成任务」与「遵守规则」之间的取舍：让 Agent 副本面对共同的不确定奖励状态，只有采取被奖励行动的副本才能「繁殖」；理论证明长期增长最大化时每种行动的执行频率应等于环境奖励它的频率；纯任务导向策略在沙盒里繁荣、在规则场景里崩溃，而经「社会化」选择压力塑造的策略更能抵抗后续压力。

为什么值得看：对齐研究借来了演化生物学的工具——不靠规则清单，而靠「环境选择」让合规行为变成生存优势；Anthropic 上市后 AI 安全与治理是各家合规刚需，这类「机制设计」背景的人才需求会跟着上来。
