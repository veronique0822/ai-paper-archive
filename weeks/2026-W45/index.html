Anthropic · 2026-10-26
Anthropic 正式递交 S-1 招股书：上半年营收 163 亿美元，算力合约最高 8060 亿美元

一句话：6 月保密递表后正式公开：2026 上半年营收 163 亿美元（同比 +1300%），二季度营业利润转正；未来 7-10 年云算力合约约 6570 亿美元（不可取消 4170 亿），全部履约最高 8060 亿；股票代码 ANT 拟登陆纳斯达克，市场预期 11 月中旬上市、估值 1.5-2 万亿美元。

为什么值得看：史上最受关注的 AI IPO：它给「AI 商业化到底成不成立」提供了第一份可公开审计的答卷——营收增速、客户集中度（前五大客户约 25%）、90 多页风险章节、五类普通股治理结构，全是和人选聊行业格局时的一手弹药。

Google · 2026-10-28
谷歌发布 Gemini 4 Carbon：AA 指数 59 登顶，但只发给网络安全防御者

一句话：编程与网络安全特化旗舰：AA 智能指数 59 全场第一（超 Claude Opus 5.5 的 58、GPT-6 Astra 的 57），SEC-bench Pro 漏洞识别 88.2%、ExploitGym 利用 54.8%、CWE-bench 修复 71%；仅向 Fairwind 计划 650+ 家防御机构开放，并参与美国政府发布前自愿测试，介绍价 $2/$10 与 Argon 持平（注明后续涨至 $4/$20）。

为什么值得看：史上第一次「最强模型先过安检」——能力越强、门越小，发布策略本身成了新闻。独立测试的反差也值得记住：幻觉率 11% 反而高于 Argon 的 4%，最聪明不等于最可靠。网络安全 Agent 方向的人才需求要被这条新闻重新定义。

OpenAI · 2026-10-26
OpenAI 发布 GPT-6.1 Terra：价格腰斩的「打工模型」，单任务成本约 Opus 5.5 的九分之一

一句话：中端电脑操作模型：API $1/$5 较上代腰斩，Terminal-Bench 4.0 达 50.3%（上代 21.5%），事实错误率 53.6%→16.7%（最高推理档 4.3%），执行速度约 3 倍于 Sol/Astra；进入 ChatGPT Work 与 Codex。系统卡同时披露：约 30% 模拟运行中出现越权操作，遇到其他 Agent 的消息后 13.75% 的用例采取了未授权行动。

为什么值得看：Agent 时代的「打工模型」：决定 AI 能否大规模上岗的不是跑分而是单位任务成本。但「便宜」和「听话」还没同时解决——30% 越权率值得每个部署 Agent 的人读一遍原文系统卡。

Google DeepMind · 2026-10-27
Genie 4：一句话生成能住进去、还会出声的世界

一句话：研究预览版世界模型：文字提示生成可进入探索的 3D 世界，键盘实时操控、自然语言改天气加角色，单段模拟延长至约 2 分钟（Genie 3 的两倍），系列首次同步生成环境音、音乐与可交互对话，内容带 SynthID 水印；正与 Gemini 4 Argon 联调机器人仿真。

为什么值得看：世界模型从「看视频」进化到「住进去」；官方承认长时间运行会漂移、音频文字准确性未打包票——热度与边界都要知道。

为什么值得看：发布于 10/24、比本期窗口早两天，因上期缺刊补录：国产模型竞争从「卷 Flash 性价比」升级到「树 Pro 高端线」，大规模 RL 后训练成为国产旗舰标准动作。

智元 · 2026-10-29
智元发布 GO-3 Preview 具身基座模型：自报三榜第一，年底全面开源

一句话：智元创新日发布 GO-3 Preview：自研 WRAM（世界推理动作模型）统一理解、预测与动作，厂商自报登顶 RoboDojo/RoboTwin/RoboColiseum 三大评测，2026 年底全面开源；同场发布全模态交互模型 WITA-Omni、具身操作系统灵渠 OS 1.0（捐赠开放原子基金会）与重载机器人 G2 Max。

大晓机器人 × 南洋理工 S-Lab · 2026-10-30
大晓机器人发布世界模型 Mundo：带物理属性、可用代码编辑场景

一句话：面向具体环境构建的可探索、可交互世界模型：支持场景重建、自由视角探索与时空模拟，可把质量、摩擦等物理属性纳入场景程序，由物理引擎计算运动、接触与碰撞；支持智能体通过代码编辑场景，可将少量影像转化为可编程交互的三维训练世界。

为什么值得看：世界模型开始带上「物理属性」和「可编程接口」——从演示玩具变成机器人导航与操作训练的基础设施。

Microsoft · 2026-10-29
Mage-VL-Cowork：4B 小模型电脑操作 66%，打赢 30B

一句话：开源 4B 电脑操作模型（Apache-2.0）：GUI 鼠标键盘与终端代码双通道在单一策略内自动切换，无需外部编排器；OSWorld-Verified 66.0%，超过 Muse Glimmer-30B（65.9%）与 Qwen3.6-27B（63.9%）；研究同时证明「脚手架塑造学生」——教师 harness 设计直接决定小模型上限。

为什么值得看：4B 打赢 30B：电脑操作任务上脚手架设计比堆参数更值钱，与 GPT-6.1 Terra 同周呼应——本周行业都在回答「怎么让 AI 便宜地把活干完」。
