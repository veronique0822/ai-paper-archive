Token 是什么？为什么大模型这周突然集体「降价大甩卖」？

2026-09-24 ｜ 小黑漫画科普 ｜ 阅读约 5 分钟 ｜ 难度：入门
导语：9 月 22 日，Anthropic 上午发布新旗舰 Claude Opus 5.5、降价 20%；约两小时后 OpenAI 发布 GPT-6 Sol 和 Luna，API 价格直接腰斩。想看懂这场「价格战」——以及它和你招人、聊人选有什么关系——只需要弄懂一个概念：Token。

一、Token：大模型世界的「计价单位」

大模型不按「字」或「句」读书写字，它把文本切成一个个小块来处理，这种小块就叫 Token（粗略理解为「半个汉字」或「四分之三个英文单词」）。

大模型读的不是「话」，是切成块的 token；账单也是按块算的。

所有模型 API 的报价单都长一个样：每百万 token 多少钱，且分两种——输入（你发给模型的内容）和输出（模型生成的内容），输出通常贵好几倍，因为「写」比「读」费算力。

🍳 类比：大模型服务就像菜市场的切配摊位。你抱着一整根大葱（一整段话）去，摊主小黑手起刀落切成葱花（token），放到秤上称重——切多少块，收多少钱。你让他再炒一盘菜（生成回答），炒出来的部分单独计价，而且更贵。

二、9 月 22 日：一条街上两家店同时降价

这天的戏剧性在于「撞车」：Opus 5.5 定价 4 美元/百万输入 token，比上一代便宜 20%；GPT-6 Sol 紧接着定价 2 美元，恰好是对手的一半；小模型 Luna 更低到 0.1 美元——不到旗舰的 1%。

同一条街，两家店，同一天把价格牌擦了重写。

为什么敢这么降？一是技术进步——新一代模型用更少算力达到同样智力，成本真的降了；二是竞争策略——能力越来越接近，价格就成了抢客户的武器。值得注意的是，这轮发布主打的不再是「谁更聪明」，而是「完成一件事花多少钱」（cost per task），这是今年评估模型的新口径。

三、缓存：账单上的「隐藏折扣」

这轮降价还有个容易被忽略的主角：提示词缓存（prompt caching）。OpenAI 把缓存命中的输入打到 1 折，Anthropic 的缓存读取也降了 60%。

第一遍慢慢读、全额收费；贴上「书签」后，下次直接翻，账单骤减。

原理很朴素：如果你多次提问都带同一大段背景材料（同一份代码库、同一份工作说明书），模型不必每次从头「重读」，把第一次读的结果存起来复用即可。读过的部分打 1 折，没读过的部分原价。对要带着长上下文反复干活的 AI Agent 来说，这一招能让账单缩水一大半。

四、和你有什么关系？（招聘视角）

  • 推理成本优化成为显学：价格战倒逼所有公司算细账，「同一个任务，怎么用最便宜的模型组合跑下来」是工程团队的日常命题。简历里出现 模型路由（model routing）、缓存策略、成本归因 的人选正在升值。
  • 「贵」不再是能力的挡箭牌：小米同日开源的 MiMo-V2.6-Pro 用 MIT 协议免费开放，单任务成本只有闭源旗舰的几十分之一。谈薪时，「我用得起贵模型」不再是价值证明，「我会选对的模型」才是。
  • Agent 落地的最后一块拼图：一个要跑几千步的 Agent，token 成本曾是最大的拦路虎；价格脚踝斩之后，许多原本「不划算」的自动化场景变得成立了。

五、聊天弹药库

  • 「你们线上业务的 token 成本是怎么压下来的？」——🟢 聊得浅：只说「我们用小模型」；🔵 聊得深：能讲缓存命中率、模型分级路由、按任务难度动态调整思考强度。
  • 「输入和输出 token 为什么要分开定价？」——🟢 聊得浅：不知道；🔵 聊得深：能说到生成是自回归逐 token 计算、比一次性读入贵得多。
  • 「如果老板让你把 AI 账单砍掉一半，你从哪下手？」——🟢 聊得浅：换便宜模型；🔵 聊得深：先上缓存、再缩短 prompt、再分级路由，最后才换模型。

收尾

一句谈资：2026 年 9 月 22 日可能会被记成「大模型价格战开打日」——同一天，Anthropic 降 20%，OpenAI 直接腰斩，小米干脆开源免费。
